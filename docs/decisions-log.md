# Decision log

Confirmed by Deepthi. Source material for ANSWERS.md.

## Who and how much
- Built for the shop **salesperson**, quoting live with the customer present.
- 12-hour budget.

## Shape
- A counter is a **chain of legs** (ADR 0001). Straight, L and U are 1, 2 and 3 legs.
- **Angled legs** and **more than three legs** are in. Bumpouts and freehand are out.
- **Length** is measured along the wall (back edge) into the corner, the way it's taped on site. Area comes from the outline.
- A **job** holds several **counters**. Each counter has its own material, edge profile, thickness and room.
- **Room** is one of Kitchen, Island, Bathroom or Other. It sets starting depth and edge defaults. An Island starts with every edge exposed.
- **Thickness**: 2 cm or 3 cm, chosen per counter and priced. 2 cm in a kitchen or island shows a warning.
- Edges and corners are stored on **leg sides**, never as outline edge numbers. They start from sensible defaults and toggle with a click.

## Pricing
- The shop's own **price list**, stored in the database and edited on a Price list page. No live market data, because shops revise their prices when suppliers announce increases.
- **Calculated in the browser.** The saved quote's line items are stored with the job (ADR 0002).
- **Price per sq ft** comes from the price group and thickness, with one row per group and thickness. Waste and installation are built into the rate.
- **Charged area** is rounded up to the next whole sq ft.
- **Line items**: edge profile per linear ft, cutouts each, faucet holes each, radius corners each, backsplash per linear ft, templating, optional tear-out, and a minimum job charge.
- **Seams** are charged only if research supports it. The slab estimate is shown as a check.
- **Saved quote** stays as saved, with a "prices have changed" notice. Editing or Re-price switches to today's prices. Every quote has a valid-until date.

## Storage
- **Relational tables, not JSON** (ADR 0003). Jobs → Counters → Legs and Cutouts. QuoteLineItems belong to Jobs, alongside the price list tables.
- **Explicit Save**, with an "Unsaved changes" marker and a warning before leaving the page.
- **Delete job**, with confirmation and cascade delete.

## Screens
- Jobs list, Job editor and Price list.
- The editor has three columns (settings, plan, live quote) with a tab per counter. New job opens straight into the editor with a sample Kitchen L.
- **Measurements** accept shop formats (`10'6`, `25 1/2`), are rounded to ⅛", stored as decimal inches and shown as feet-inches.
- **Impossible shapes stop the quote**: zero or unreadable sizes, overlapping legs, a cutout that doesn't fit. Unusual shapes only warn.
- A view-only **3D preview** gets built last, if time allows.
- A **PDF quote** is generated by the backend with QuestPDF. It's built from the saved quote, using the plan SVG the browser sends on save.

## Process
- First commit is the untouched starter. Then one branch and PR per feature, each with a code review.
- Test-first (Vitest) for the parser, geometry and pricing. xUnit for the API.
- CI runs on every push and PR. Branch protection requires CI to pass.
- **Release**: a version tag builds the submission ZIP, checks it's under 25 MB, unzips it, builds it, runs the tests and attaches it to a GitHub Release.
- **Research**: AI gathers sources (`docs/research/pricing.md`), and Deepthi checks them and decides.
- **ANSWERS.md**: AI drafts, Deepthi edits. §3 states plainly what AI did.

## Overruled AI recommendations
- Storage: AI suggested JSON on the job. Chose tables instead.
- Thickness: AI suggested a fixed 3 cm. Chose 2 cm and 3 cm, priced.
- PDF: AI first suggested the browser's print view. Chose a real PDF.
- Process: added branch protection and release automation to AI's lighter plan.
